## Scope

**In**
- 5 presets, each with a lead chain and a matching doubles chain
- Mix versions only, built for dry recordings
- Toolkit: FL Studio stock + Auto-Tune Artist + Fresh Air + FabFilter. Nothing else
- Maxed-out chains: all 10 mixer slots plus parallel and send tracks as needed
- Body added across the board to offset a thin raw vocal
- Chains that handle both rapping and melodies
- Placement set per preset, following each Phase 1 concept
- Mixes that translate on any playback system, mono included
- Key automation moves per preset, not a full automation map
- Small upgrades to the Phase 1 concepts where they sound better
- Delivered as markdown chain sheets: settings plus short reasons

**Out**
- Ad-lib chains
- Chains for sung harmony takes (Silk Stack builds its harmonies from the lead)
- Low-latency tracking versions
- Level-matching for switching presets mid-song
- Free or newly bought plugins
- FL preset files (the deliverable is docs)
- Beat processing, mix bus and mastering
